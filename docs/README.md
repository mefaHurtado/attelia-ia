# Documentación de Attelia

- originales/: documentos originales descargados y conservados según sus condiciones de uso.
- resumenes/: síntesis propias en español, organizadas por tema y con referencias.
- conocimiento/: archivos TXT preparados para la base vectorial.
- fuentes.md: inventario de fuentes y estado de revisión.

Las síntesis deben distinguir los hechos respaldados por las fuentes
de las recomendaciones generales y registrar la referencia de origen.
